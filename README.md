# 🏎️ Dashboard Comercial Porsche | Análise de Dados

Um dashboard interativo desenvolvido com **HTML**, **CSS** e **JavaScript** para análise de vendas da Porsche. O projeto transforma dados comerciais em informações estratégicas por meio de indicadores (KPIs) e gráficos interativos.

## 🌐 Acesse o projeto

🚀 **Dashboard Online:** https://jessica-apc.github.io/dashboard-porsche/

📂 **Repositório GitHub:** https://github.com/jessica-apc/dashboard-porsche

---

## 📖 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de aplicar conceitos de **Análise de Dados**, **Visualização de Dados** e **Desenvolvimento Web**, transformando uma planilha de vendas em um dashboard interativo capaz de apoiar a tomada de decisões.

Os dados utilizados passaram por um processo de tratamento (Sanitized) e foram convertidos para o formato JSON para consumo pelo JavaScript.

---

## 🎯 Perguntas de negócio respondidas

O dashboard foi desenvolvido para responder às seguintes questões:

- 📍 Qual cidade gerou o maior faturamento?
- 🚗 Quais modelos representam a maior parte das vendas?
- 📈 Como as vendas evoluíram ao longo do período analisado?

---

## 📊 Indicadores (KPIs)

- 🚗 Total de vendas
- 💰 Faturamento total
- 💵 Ticket médio
- 🌍 Quantidade de cidades atendidas

---

## 📈 Visualizações

- Faturamento por cidade
- Modelos mais vendidos
- Evolução das vendas
- Distribuição das formas de pagamento
